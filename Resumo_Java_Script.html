JAVASCRIPT


O JavaScript é uma linguagem de programação conhecida como linguagem da web, pois é através desta linguagem que as páginas web se tornam interativas e se tornam "clicáveis", sendo assim veremos tudo o que você Desenvolvedor precisa fazer para desenvolver páginas web com JavaScript

Estruturas para desenvolvimento

As páginas web têm sua estrutura dividida em pastas, sendo uma pasta geral para o projeto: pasta index.html para arquivos .html; pasta chamada scripts com o main.js, para funções e interações com JavaScript

A seguir uma simples estrutura contendo o html e JavaScript, para adicionar CSS basta adicionar uma pasta chamada styles com o arquivo em .css
projeto ├── index.html └── scripts └── main.js

Integração de um arquivo JavaScript ao html

Para integração entre JavaScript e html deve-se adicionar o elemento html <script> usando o atributo <src> para especificar a URL (caminho) do arquivo JavaScript que desejo integrar.




<!DOCTYPE html>

<html>

<head lang="pt-br">

    <meta charset="UTF-8">

    <title>Exemplo</title>

    <link rel="stylesheet" href="styles/main.css" type="text/css">

</head>

<body>

    <script src="scripts/main.js"></script>

</body>

</html>

Definindo JavaScript diretamente sem HTML

Esta abordagem geralmente não é recomendada pelo excesso de linhas e bagunça no código, mas de uma maneira simples. Para definir o JavaScript sem o HTML, não se usa o src como no tópico anterior. Usa-se o elemento <script> também para definir internamente como o exemplo abaixo onde será impresso um Olá mundo.




<!DOCTYPE html>

<html>

<head lang="en">

    <meta charset="UTF-8">

    <title>Example</title>

    <link rel="stylesheet" href="styles/main.css" type="text/css">

</head>

<body>

    <script>

        alert('Hello World');

    </script>

</body>

</html>
Esta definição somente é aplicada em casos excepcionais

Ainda há o elemento <noscript> que é usado quando o navegador não suporta JavaScript




<noscript>

    Conteúdo alternativo para usuários sem JavaScript.

</noscript>

Console do Desenvolvedor

O console do desenvolvedor faz parte das ferramentas do navegador e permite visualizar erros, testar códigos e manipular páginas em tempo real.

Em algumas plataformas para abri-lo usa-se os seguintes passos:

Chrome: Exibir -> Desenvolvedor -> Console JavaScript

Firefox: Ferramentas -> Desenvolvedor Web -> Console Web

Safari: Desenvolvedor -> Mostrar Console de Erros

Em versões atuais do Safari, primeiro é necessário habilitar o menu Desenvolvedor em Preferências -> Avançado.

Opera: Desenvolvedor -> Ferramentas do Desenvolvedor -> Aba Console

Microsoft Edge: pressione F12 ou acesse Outras Ferramentas -> Ferramentas de Desenvolvimento


Os navegadores disponibilizam um objeto chamado console, que possui vários métodos para exibir mensagens. Por exemplo, você pode usar o método log() para enviar uma mensagem simples ao console.




console.log('Olá Mundo do Desenvolvedor');

Sendo a mensagem: Olá Mundo do Desenvolvedor impressa


Métodos do console




console.log('Olá Mundo do Desenvolvedor');

// Exibe uma mensagem normal



console.debug('Olá Mundo do Desenvolvedor');

// Exibe uma mensagem de depuração



console.error('Olá Mundo do Desenvolvedor');

// Exibe uma mensagem de erro



console.info('Olá Mundo do Desenvolvedor');

// Exibe uma mensagem informativa



console.warn('Olá Mundo do Desenvolvedor');

// Exibe uma mensagem de aviso

Há outros métodos como o clear() que limpa as mensagens exibidas no console; debug() exibe a mensagem apenas quando o nível de depuração (debug) está habilitado; error() exibe uma mensagem de erro. A maioria dos navegadores mostra um ícone de erro ao lado da mensagem; info() exibe uma mensagem informativa no console; log() exibe uma mensagem comum no console; warn() exibe uma mensagem de aviso. Normalmente é acompanhada por um ícone de alerta.

APRENDENDO JAVASCRIPT

Aprenderemos conceitos chaves para programar na web usando JavaScript, cada conceito é útil para fazer aplicações desde simples a avançadas.

Variáveis

Como as demais linguagens de programação as variáveis são "espaços" na memória onde valores são armazenados e a partir daí manipulados conforme o objetivo do programa. A declaração de variáveis está baseada no let para valores que podem ser modificados ao longo do tempo. JavaScript é uma linguagem dinamicamente tipada, ou seja a mesma regra de variável let define strings, float, int e double, semelhante ao Python. let define a regra de escopo, ou visibilidade da variável.

  • let Nome; // Declaração de variável
  • Nome = 'João'; // Inicialização da variável
  • let Nome = 'João'; // pode-se declarar na mesma linha
  • // Imprimir variável console.log(Nome); // Resultado João

Existem também as constantes que são variáveis que uma vez declaradas com const não podem mudar. exemplo: const MAX = 500;

Tipos de Dados

JavaScript fornece vários tipos diferentes de dados, cada tipo de dado serve para um propósito diferente.

Dados Numéricos
const num1 = 5; // definição de um número inteiro
const num2 = 0.5; // definição de um número decimal
const num3 = -22; // definição de um inteiro negativo
const num4 = -0.9; // definição de um decimal negativo

Também pode-se declarar em "let"

Strings

Representam uma cadeia de caracteres, letras ou números, de forma simples é texto

const primeiroNome = 'John'; // aspas simples
const segundoNome = "Doe"; // aspas duplas
const idade = "22"; // não é um número, mas uma string
const cidade = 'São paulo"; // erro de sintaxe: aspas misturadas

Uma boa prática em JavaScript é utilizar a palavra-chave const para todos os valores que não mudam. Estritamente falando, esses valores deixam de ser variáveis e passam a ser constantes.

Valores booleanos

Assumem apenas valores True (verdadeiro) e False (falso)

let cliente = true;
let adm = false;

JavaScript também possui vários outros tipos de dados, entre eles podemos citar o undefined que indica que uma variável foi criada e nenhum tipo de valor foi atribuído a ela; temos o null que representa a ausência intencional de um valor ou objeto; há o BigInt usado para representar números inteiros extremamente grandes, que ultrapassam o limite seguro do tipo number; temos o Symbol que cria um identificador único e imutável, muito utilizado para evitar conflitos de nomes em propriedades de objetos. Há também o tipo de dados complexo ou estrutural que neste caso é o object, que é um bloco de construção fundamental para dados complexos em JavaScript. Inclui estruturas como Objetos, Arrays (listas) e Funções.

Condicionais

Condições com base naquilo que você quer que o programa tenha um norte conforme eventos vão acontecendo. Abaixo há um exemplo das condicionais IF/ELSE e SWITCH.

condição if (se), e else (senão)




// Solicita a idade do usuário

let idade = prompt("Digite sua idade: ");



// Converte o valor digitado para número

idade = Number(idade);



// Verifica se é maior ou menor de idade

if (idade >= 18) {

    console.log("Você é maior de idade.");

} else {

    console.log("Você é menor de idade.");

}

Exemplo de condição com senha




//senha de um sistema

let senha = prompt("Digite a senha: ");



if(senha === "1823"){

    alert("Acesso liberado"); //alert é usado para impressão na tela do navegador.

} else{

    alert("Erro! Senha errada!");

}

Switch case define uma condição com base no caso a ser atendido, semelhante ao if/else, mas com algumas mudanças. Cada um serve para aplicações diferentes.




// Solicita o dia da semana

let dia = prompt("Digite um dia da semana: ");



// Converte para minúsculas para facilitar a comparação

dia = dia.toLowerCase();



switch (dia) {

    case "terça":

    case "quarta":
    case "quinta":

    case "sabado":
    case "domingo":

        console.log("É fim de semana.");

Loops

Loops são usados para determinadas instruções que se repetem. A seguir veremos 3 exemplos de loops JavaScript e seus usos.

Loop de contagem: usado para repetir instruções com base em uma variável contadora. A seguir um exemplo simples de loop de contagem que exibe os números de 1 a 10 no console.




for (let i = 1; i <= 10; i++) {

    console.log(i);

}

Loop com teste no início: repete instruções enquanto uma determinada condição for verdadeira. A seguir um loop com teste no início (while loop), a condição booleana é verificada antes da primeira iteração. Somente se ela for verdadeira o bloco será executado. Portanto, é possível que nenhuma iteração seja realizada.




// Imprime números de 1 a 10



let i = 1; // Inicialização



while (i <= 10) { // Condição

    console.log(i); // Instrução

    i++; // Incremento

}

Loop com teste no final: também repete instruções enquanto uma condição for verdadeira, mas verifica a condição após cada execução do bloco. Este loop é chamado de do-while loop, a condição só é verificada após a execução do bloco. Em outras palavras, pelo menos uma iteração sempre será executada, mesmo que a condição já seja falsa no início.




// Um loop do-while simples que exibe números de 1 a 10

let i = 1; // Inicialização



do {

    console.log(i); // Instrução

    i++; // Incremento

} while (i <= 10); // Condição

Funções

Funções de uma maneira simples e prática é um bloco de código reutilizável projetado para realizar uma determinada função ou tarefa no código, deixando-o mais organizado, limpo e facilita a manutenção. A seguir você verá exemplos de declarações e usos de funções em JavaScript.




function ImprimirNumeros() { // Imprime números de 1 a 10

    for (let i = 1; i <= 10; i++) {

        console.log(i);

    }

}

Em JavaScript existem as expressões de funções. Nesse caso, você não especifica um nome para a função, tornando-a uma função anônima (anonymous function), e a armazena em uma variável.




const soma = function(a, b) {

    return a + b;

};



console.log(soma(2, 3));  // Retorna 5

Chamada de função




ImprimirNumeros();

Parâmetros para função




function somar(a = 0, b = 0) {

    return a + b;

}

somar(5, 10); // Retorna 15

somar(5); // Retorna 5 (b assume 0)

Funções com retorno




function soma(x, y) {

    let result = x + y; // Soma dos 2 parâmetros recebidos

    return result;  // Retorno do resultado

}



const z = soma(5, 6); // Chamada da função e atribuição do retorno

console.log(z);  // Resultado 11

Objetos

Além dos tipos de dados primitivos, o JavaScript também fornece objetos e arrays. Você pode usar objetos para agrupar funcionalidades relacionadas de maneira organizada. Já os arrays funcionam como listas, permitindo armazenar múltiplos valores.

OBJETOS: você pode criar objetos de várias maneiras, mas de maneira simples os objetos possuem propriedades (que armazenam dados) e métodos (funções associadas ao objeto). A seguir um exemplo de objeto livro com suas propriedades e um método. (O objeto é semelhante a uma struct em C)




const livro = {

    titulo: 'JavaScript - The Comprehensive Guide',

    valor: 59.99,

    autor: 'Philip Ackermann',

    isbn: '978-1-4932-2287-2',



    printDescricao() {

        console.log(`${this.autor}: ${this.titulo}`);

    }

}



console.log(livro.titulo);

// "JavaScript - The Comprehensive Guide"



console.log(livro.valor);

// 59.99



console.log(livro.autor);

// "Philip Ackermann"



console.log(livro.isbn);

// "978-1-4932-2287-2"



livro.printDescricao();

// "Philip Ackermann: JavaScript - The Comprehensive Guide"

Array

Arrays funcionam como listas de valores e, assim como os objetos, podem ser criados de várias formas em JavaScript. Um array é definido usando colchetes []. Os elementos são escritos dentro dos colchetes e separados por vírgulas. Além disso, novos valores podem ser adicionados posteriormente usando o método push().




// Criando um array com valores iniciais

const nomes = ['João', 'James', 'Peter'];



// Acessando elementos do array

console.log(nomes[0]); // "João"

console.log(nomes[1]); // "James"

console.log(nomes[2]); // "Peter"



// Criando um array vazio

const cores = [];



// Adicionando valores

cores.push('vermelho');

cores.push('verde');

cores.push('azul');



// Adicionando valores por índice

cores[3] = 'laranja';

cores[4] = 'amarelo';



console.log(cores);

// ["vermelho", "verde", "azul", "laranja", "amarelo"]



// Percorrendo um array

for (let i = 0; i < cores.length; i++) {

    console.log(cores[i]);

}

Há muitos outros métodos além do push() para trabalhar com arrays, por exemplo: concat() adiciona elementos ou outros arrays a um array existente; filter() filtra elementos do array com base em um critério definido por uma função; pop() remove o último elemento do array; sort() ordena os elementos do array, opcionalmente usando uma função de comparação, entre outros.
