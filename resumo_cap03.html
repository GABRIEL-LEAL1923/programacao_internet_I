INTRODUÇÃO E PRINCÍPIOS DE CSS


CSS define o layout e o design de páginas html. Ele é usado na maioria dos sistemas da web atuais. CSS = Cascade Style Sheets tem cores definidas por padrão RGB/HEXADÉCIMAL. A seguir veremos as aplicações de CSS e determinados estilos.

LINKAGEM DE PÁGINAS HTML COM CSS

Processo que liga css ao HTML, sendo possível fazer diretamente (interno), externo ou embutido no arquivo.html. Este processo abaixo fixa 2 arquivos, mais específicamente um .CSS dentro de um .HTML para assim dá vida ao texto HTML, sendo feito um arquivo.css and um arquivo.html, fixando ele junto do arquivo.html no ínicio <head/>

CSS EXTERNO

Há o processo que liga CSS e HTML de modo externo sendo este fixado em um arquivo.css.

<link href="css/styles.css" type="text/css" rel="stylesheet"/>

CSS EMBUTIDO

Já o CSS embutido fixa-o por meio de código em conjunto com o HTML.

Exemplo linkagem html externas:

 
<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Exemplo CSS Embutido</title>

    <style>
        body {
            background: #f4f4f4;
            font-family: Arial, sans-serif;
            padding: 40px;
        }

        .caixa {
            background: #3498db;
            color: white;
            padding: 20px;
            border-radius: 10px;
            width: 300px;
            text-align: center;
            margin: auto;
            box-shadow: 0 4px 10px rgba(0,0,0,0.2);
        }

        .caixa:hover {
            background: #2980b9;
            transform: scale(1.05);
            transition: 0.3s;
        }
    </style>
</head>

<body>

    <div class="caixa">
        Exemplo de CSS embutido no HTML
    </div>

</body>
</html>

CSS INTERNO

É usado dentro das linhas do html, sendo sua principal caracteristica o uso do <style/>


<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>JavaScript Interno</title>
</head>

<body>

    <h1 id="titulo">Olá Mundo</h1>

    <script>
        const titulo = document.getElementById("titulo");

        titulo.style.color = "blue";

        titulo.innerHTML = "Texto alterado com JavaScript interno!";
    </script>

</body>
</html>

Cada tipo de criação e aplicação de arquivos CSS depende de sua aplicação:

Linkagem externa é usado na maioria dos casos facilita o uso e manutenção do código

Linkagem interna, aplica-se a páginas que não mudam ou são páginas de anúncios, de restrição "Algo que mantém padrão"

linkagem embutida é usada em testes e aplicações de emergência como emails marketing e aplicações pequenas e que não alteram

HERANÇA EM CSS

Herança em CSS ocorre quando um elemento herda uma 'tag' específica em seu escopo, por exemplo a especificação de cores (collor) e ou uma fonte (font-family) para o elemento body (corpo, escopo) todos os elementos "fontes" e "cores" serão adotados dentro de body. Há alguns elementos que não podem ser herdados, eles são elementos que são "privados", ou seja não são regras que podem ser aplicadas de modo geral mais específico, isto por exemplo pode ser aplicado a uma borda que não é geral mais especifica de uma parte do escopo da página.

APLICAÇÕES CSS NO DESIGN DE PÁGINAS

VALORES RGB: Este padrão de cores é muito usado em aparelhos eletrônicos, é uma mistura de R (red), G (greem), B (blue). Cada componente é descrito de números indo deste o 0 ao 255 no seguinte padrão rgb(255, 255, 255), este mesmo padrão pode formar todas as outras cores e suas variáções

VALORES HEXADÉCIMAIS(HEX): São cores representadas pelos números hexadécimais (um valor de 6 dígitos), um exemplo é o amarelo representado pelo hexadécimal #ffff00 ou o branco representado pelo hexadécimal #ffffff.

NOMES DE CORES EM INGLÊS: Representa-se o nome das cores em inglês por exemplo yellow para amarelo, blue para azul, além de varias outras cores.

VALORES RGBA: Desde a atualização do CSS3 é possível definir a opacidade da cor aplicada no RGB por exemplo usa-se a conotação 0.0 de transparete a 1.0 que é totalmente opaco, um exemplo de um amarelo com 50% de opacidade seria rgba(255, 255, 0, 0.5).

VALORES HSL: Há também desde o CSS 3 o uso da cor com base na matriz, por exemplo hsl(60,100%,50%) que é o amarelo ,definido pela matriz (hue), saturação (saturation) e luminosidade (lighness).

VALORES HSLA: Semelhante ao RGBA, adiciona opacidade ao valor HSL acrescentando um quarto número, por exemplo o amarelo com 50% de opacidade seria hsla(60,100%,50%,0.5).

DEFINIÇÃO DE FONTES E TAMANHOS

Fonte é definida em CSS por (font-family) este define fonte, específicada pelo desenvolvedor. Opcionalmente deve-se especificar várias fontes separadas por vírgula para caso o navegador não consiga carregar uma, outras alternatvas estão a disposição. Abaixo exemplos de aplicação de fontes em diferentes casos (Para mais informações visite o site)->Tutorial de fontes CSS


<style>
body {
  font-family: 'Times New Roman', Times, serif;
}

h1, h2 {
  font-family: Arial, sans-serif;
}

ul li {
  font-family: 'Courier New', Courier, monospace;
}

.author {
  font-family: Verdana;
}

.date {
  font-family: 'Courier New', Courier, monospace;
}
</style>

Ajustes no tamanho da fonte são feitos sob "px" - pixels, "%" - porcentagem, ou "em" - unidade para tamanho de fontes. 


<style>
body {

  /* font size of 14 pixels */
  font-size: 14px;
}

h1 {

  /* 150% of the regular font size */
  font-size: 150%;
}

h2 {

  /* 1.5 times the width of the letter m */
  font-size: 1.5em;
}
</style>

Ajuste de fonte por estilo, é muito usado em itálico e negrito 


<style>
.introduction {

  /* italico */
  font-style: italic;

  /* Bold font */
  font-weight: bold;
}
</style>

LAYOUT E BASE DE SITES CSS

Com CSS podemos posicionar elementos html e assim criar a estrutura de um layout por exemplo de um site, pois este constitui de vários blocos que quando possicionados fazem um site ter sua estrutura. A princípio o html distingue elementos em nível de bloco e elementos em nível de linhas, estes por sua vez quando fixados com a propriedade CSS "display" tem a possibilidade de personalizar o comportamento em relação ao fluxo de texto. "block" garante que o html seja considerado no layout nível bloco, já "inline" personaliza para que o elemento seja considerado nível de linha.

OS elementos podem ser formatados:

POSICIONAMENTO ESTÁTICO: "static" -Os elementos são posicionados conforme o fluxo do texto html

POSICIONAMENTO RELATIVO: "relative" -Os elementos são posicionados de forma relativa para cima, para direita, ou com base no fluxo normal

POSICIONAMENTO ABSOLUTO: "absolute" - Os elementos são removidos do fluxo normal e posicionados em relação ao elemento pai.

POSICIONAMENTO FIXO: "fixed" -Os elementos são posicionados em relação à janela do navegador (também chamada de viewport).

POSICIONAMENTO COLADO: "sticky" -Os elementos se comportam de forma semelhante ao posicionamento fixo em termos de posicionamento, mas rolam apenas até um ponto especificado e depois permanecem fixos na viewport.

POSICIONAMENTO HERDADO: "inherit"-Neste caso, o comportamento de posicionamento é herdado do elemento pai.

PRINCÍPIO DO LAYOUT FLOAT

Você pode usar o layout flutuante (float layout) para influenciar o comportamento dos elementos em relação ao fluxo do texto. A propriedade CSS correspondente float pode ser usada para fixar elementos na margem esquerda ou direita do bloco HTML delimitador. Por muito tempo, o layout float foi a escolha principal para organizar elementos. Agora, no entanto, você tem duas alternativas o layout flexbox e o layout grid a seguir iremos tratar do layout grid


No layout grid os elementos individuais organizados usando o layout grid podem, portanto, ser dispostos em duas dimensões em vez de apenas uma, como ocorre com o layout flexbox, tornando muito mais fácil a implementação de layouts complexos. ALGUMAS DEFINIÇÕES: grid-template-columns (Contêiner Grid): Define o número e o tamanho das colunas do grid. grid-template-rows (Contêiner Grid): Define o número e o tamanho das linhas do grid. grid-auto-columns (Contêiner Grid): Define o número e o tamanho das colunas criadas automaticamente no grid. grid-auto-rows (Contêiner Grid): Define o número e o tamanho das linhas criadas automaticamente no grid. grid-auto-flow (Contêiner Grid): Define como os elementos posicionados automaticamente "fluem" dentro do grid. grid-template-areas (Contêiner Grid): Define a estrutura e a posição dos elementos do grid definidos via grid-area. grid-template (Contêiner Grid): Propriedade abreviada para grid-template-areas, grid-template-columns e grid-template-rows. grid (Contêiner Grid): Propriedade abreviada para grid-auto-columns, grid-auto-flow, grid-auto-rows e grid-template. POSICIONAMENTOS: grid-row-start (Item Grid): Define o início vertical de uma área do grid. grid-column-start (Item Grid): Define o início horizontal de uma área do grid. grid-row-end (Item Grid): Define o final vertical de uma área do grid. grid-column-end (Item Grid): Define o final horizontal de uma área do grid. grid-row (Item Grid): Propriedade abreviada para grid-row-start e grid-row-end. grid-column (Item Grid): Propriedade abreviada para grid-column-start e grid-column-end. grid-area (Item Grid): Propriedade abreviada para grid-row e grid-column.

ALINHAMENTO: justify-self (Item Grid): Define o alinhamento de um item do grid dentro de sua célula. justify-items (Contêiner Grid): Define o alinhamento de todos os itens do grid dentro de suas respectivas células ao longo do eixo horizontal. align-self (Item Grid): Define para um item do grid como ele é posicionado ao longo do eixo transversal. align-items (Contêiner Grid): Define para um contêiner grid como os itens individuais são posicionados ao longo do eixo transversal. justify-content (Contêiner Grid): Define a distribuição do espaço ao longo do eixo principal. align-content (Contêiner Grid): Define a distribuição do espaço ao longo do eixo transversal (o eixo definido como o que não é o eixo principal). ESPAÇAMENTO: row-gap (Contêiner Grid): Define as distâncias entre as linhas individuais de um grid. column-gap (Contêiner Grid): Define as distâncias entre as colunas individuais de um grid. gap (Contêiner Grid): Propriedade abreviada para row-gap e column-gap.
