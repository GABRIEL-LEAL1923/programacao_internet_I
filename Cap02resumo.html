ESTRUTURA BÁSICA PADRÃO DE PÁGINA HTML

Não sendo complexa uma página .html é estruturada de maneira simples, abaixo um padrão mínimo usado para criar uma página .html na web. 


<!DOCTYPE html> *usado para definir o tipo da página
<html>  *define página web .html 
<head>  *define neste escopo metadados ou dados de configurações para o navegador 
    <title>Primeira página</title> *define o título da página na web
</head> *fecha o escopo de configuração de metadados para o navegador 
<body> *corpo da página web

    <h1>Título do site</h1> *titulo da página web (conteúdo)
    <h1>Olá, web!</h1> *h1 é para titulos grandes 
    <p>site 0.1</p> *esta tag que circula site 0.1 define os paragrafos
    <b>negrito</b> *define uma frase ou texto em negrito 

</body> *fecha o corpo da página web 
</html> *fecha a definição da página web 

 *NOTA: note que ao fechar as tags usam uma " / " (barra).

Parametizando elementos por atributos (Links de exemplos)

A ação de parametizar elementos por links é uma forma de deixar links clicaveis e assim garantir que estes links direcionem o usuário para uma página web seja interna ou externa. Exemplo abaixo: 


<h1>
    <a href="https://www.uol.com.br">+Informações Clique aqui</a>
</h1>

< a = âncora que define o escopo do link e seu texto 
href = referência (URL da página) 
"https://www.uol.com.br" = endereço URL da página desejada]

HTML na Criação de listas

As listas em html tem muito valor, por exemplo na listagem de dados sobre compras para o usuário em uma loja virtual, uma lista dos primeiros colocados em um evento que foi públicado na web, além de muitas outras milhares de aplicações. Abaixo estão os tipos de listas usados em html 


ORDENADAS (COM ORDEM): Usadas em ordem para elementos listados em ordem.

<ol> *esta tag diz "ordered list" ordenação de lista 
    <li>primeiro</li> *esta tag que circula o nome primeiro diz item de lista "list item" por isto li
    <li>s;segundo</li>
    <li>terceiro</li>
</ol>


NÃO ORDENADAS (SEM ORDEM): É uma  lista mais não esta em ordem, imagine uma lista de compras por exemplo

<ul> esta tag diz *"unodered list" lista não ordenada
    <li>maçã</li> *da mesma forma o li representa lista de itens
    <li>pera</li>
    <li>alface</li>
</ul>


LISTA DE DESCRIÇÃO (TERMO + DESCRIÇÃO): Estas são listas que possuem títulos + descrição em baixo

<dl> *elemento tag que cria este tipo de lista "desfinition list"
    <dt>CSS</dt> *a tag dt diz "definition de term" ou seja definição de termo "título" da lista a ser descrita
    <dd>Cascading Style Sheets</dd> *tag que diz "definition description" definição do termo descrito 

outro exemplo: 
    <dt>HTML</dt>
    <dd>Linguagem de marcação de texto</dd>
</dl>
DEFINIÇÃO DE LISTAS ANINHADAS:

Váriação de lista que define listas com seus títulos e grupos, uma especie de agrupamento, veja o padrão e compare com as demais listas acima 


<ul>
    <li>
        FRUTAS:
        <ul>
            <li>maçã</li>
            <li>laranja</li>
        </ul>
    </li>

    <li>
        VEGETAIS:
        <ul>
            <li>alface</li>

*Nota: Note que as listas sempre como todos os padrões .html iniciam com tag de início e finalizam com tags geralmente identificadas com " / " (barra).

DEFINIÇÃO DE LINKS 


LINKS EXTERNOS: Links que direcionam para outros sites.

<a href="https://www.uol.com.br">Página do UOL</a>

 Abre um site fora da página atual.


LINKS INTERNOS: Levam o usuário para dentro do próprio site, mais especificamente para uma 
determinada parte especifica.

<a href="#cap_01">Capítulo 01</a>

<h2 id="cap_01">Página inicial</h2>

 Leva o usuário para uma parte da mesma página.

LINKS RELATIVOS: Levam para outras páginas dentro do mesmo website.

*Exemplo de página .html com link relativo a uma página no mesmo website.

<a href="index.html">Página Inicial</a>

<a href="about.html">Sobre HTML</a>

INCLUSÃO DE IMAGENS: Inclue imagens na página web.

<img src="images/profile.jpg" 
     alt="Meu arquivo"
     title="Este é o arquivo WA"> 

 src = caminho da imagem  
 alt = texto alternativo  "Plano B"
 title = título da imagem

ESTRUTURA DE TABELAS

Dados em tabelas são distruibuidos em linhas e colunas. 



<table> *define a tabela

    <tr> *define as linhas
        <th>Primeiro Nome</th>
        <th>Segundo Nome</th>
    </tr>

    <tr> 
        <td>Riana</td> *define as colunas
        <td>João</td>
    </tr>

</table>
